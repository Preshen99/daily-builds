# daily-builds

One small project a day, written by hand.

I'm a full-stack developer (C#/.NET, SQL Server, PostgreSQL, TypeScript, React/Vue/Angular). I use AI tools every day at
work, and I want my fundamentals to be solid enough to judge what they give me. So this repo has one rule:

> **No AI.** Official docs, books and search are fine. Code is typed by me.

Each folder is one build: a challenge with a brief, acceptance criteria and rules, built in roughly 30–60 minutes.
They start at the basics and climb: foundations → core craft → applied → senior → lead/staff → principal.

## Tracks

**Software path:** C# & ASP.NET Core · SQL (SQL Server & PostgreSQL) · TypeScript & JavaScript ·
HTML, CSS & Tailwind · Python · data structures & algorithms · clean code, testing & patterns ·
docs & Mermaid diagrams · Git, CI/CD & cloud · system design & architecture

**AI branch:** prompt engineering & understanding models · agents, skills & MCP · LLM apps by hand (RAG, embeddings, evals)

## Layout

```
<yyyy-mm-dd>-<slug>/
  README.md     what the challenge was, what I learned, what I'd do differently
  ...           the code
```

## How it works

A challenge is issued each weekday morning. I build it, push it, and log how long it took and how hard it felt.
The next morning the build gets a code review and the next challenge is pitched from how that one went.
Some weeks focus on a single track to go deep.
